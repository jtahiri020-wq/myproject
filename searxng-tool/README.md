# دليل الإعداد: SearXNG + أداة البحث عن صفحات فيسبوك/انستغرام

يوجد طريقتان لتشغيل هذا المشروع. اختر ما يناسبك:

- **الطريقة أ (موصى بها لك):** كل شيء على GitHub، بدون تثبيت أي برنامج على جهازك.
- **الطريقة ب:** تشغيل محلي على جهازك عبر Docker.

---

## الطريقة أ: التشغيل الكامل على GitHub (بدون تثبيت شيء)

### 1. إنشاء مستودع (Repository)
1. أنشئ حسابًا على https://github.com إن لم يكن لديك.
2. أنشئ مستودعًا جديدًا (New repository)، اختر أي اسم (مثلاً `social-finder`)، واجعله **Private** إن أردت.
3. ارفع إليه كل الملفات الموجودة في هذا المجلد بالكامل (بما فيها مجلدي `.github` و `searxng-config` كما هما — لا تغيّر أسماء المجلدات):
   - عبر الواجهة: زر "Add file" → "Upload files"، ثم اسحب كل الملفات والمجلدات.
   - أو عبر git: `git init && git add . && git commit -m "init" && git remote add origin <رابط المستودع> && git push -u origin main`

### 2. رفع ملف الـ CSV الخاص بك
ارفع ملف مشاريعك (مثلاً `مشاريعي.csv`) في جذر المستودع، بنفس طريقة رفع الملفات أعلاه.
تأكد أنه محفوظ بترميز UTF-8.

### 3. تشغيل الأداة
1. اذهب لتبويب **Actions** في أعلى صفحة المستودع.
2. من القائمة اليسرى، اختر "البحث عن صفحات فيسبوك وانستغرام".
3. اضغط الزر الأزرق **Run workflow**.
4. املأ الحقول التي تظهر:
   - `csv_path`: اسم ملفك، مثلاً `مشاريعي.csv`
   - `name_column`: الاسم الحقيقي لعمود اسم المشروع في ملفك
   - `city_column`: الاسم الحقيقي لعمود المدينة
   - `delay`: اتركه 3 (لا تقلّل عن 1)
5. اضغط **Run workflow** الأخضر.

### 4. تحميل النتائج
1. انتظر حتى تنتهي العملية (ستظهر علامة ✓ خضراء)، المدة تعتمد على عدد المشاريع (كل مشروع يأخذ ~5-10 ثوانٍ).
2. افتح التشغيل (الصف الذي انتهى)، انزل لأسفل الصفحة إلى قسم **Artifacts**.
3. حمّل الملف المسمى "نتائج-البحث" (سيكون بصيغة zip يحتوي `results.csv`).

### ملاحظة مهمة
سيرفرات GitHub تستخدم عناوين IP مشتركة قد تُحظر أحيانًا من بعض محركات البحث بشكل مؤقت مقارنة بجهازك الشخصي. إذا لاحظت نتائج فارغة بشكل غير طبيعي، جرّب زيادة `delay` إلى 5 أو 6، أو استخدم الطريقة ب.

## الطريقة ب: التشغيل المحلي عبر Docker

### المتطلبات
- Docker Desktop: https://www.docker.com/products/docker-desktop

### الخطوات
1. افتح Terminal في مجلد المشروع وشغّل:
   ```bash
   docker compose up -d
   ```
2. انتظر 10-15 ثانية، ثم تأكد أن JSON يعمل (الإعداد مُفعّل تلقائيًا من ملف `searxng-config/settings.yml`):
   ```
   http://localhost:8080/search?q=test&format=json
   ```
   يجب أن ترى نص JSON مباشرة (لا خطوات يدوية إضافية مطلوبة).

3. ثبّت متطلبات بايثون:
   ```bash
   pip install requests rapidfuzz --break-system-packages
   ```
   (على ويندوز بدون `--break-system-packages`)

4. شغّل الأداة:
   ```bash
   python3 find_social_pages.py --input مشاريعي.csv --output النتائج.csv --name-column اسم_المشروع --city-column المدينة
   ```

## شكل ملف النتائج (في كلتا الطريقتين)
لكل مشروع:
- أفضل رابط فيسبوك + درجة الثقة + العنوان الذي وجدته
- أفضل رابط انستغرام + درجة الثقة + العنوان
- عمود `يحتاج_مراجعة`: يشير للحالات غير المؤكدة التي يجب عليك مراجعتها بعينك
- عمود بأفضل 3 احتمالات لكل منصة (نصية، مفصولة بـ `|`) للرجوع إليها إن لم يكن الخيار الأول صحيحًا

## خيارات إضافية للسكريبت (تعمل محليًا؛ في GitHub Actions بعضها متاح عبر حقول workflow)
- `--url` رابط SearXNG (افتراضي `http://localhost:8080`)
- `--top-n` عدد الاحتمالات المحفوظة لكل منصة (افتراضي 3)
- `--delay` ثواني الانتظار بين كل بحث (افتراضي 2، لا تقلل عن 1)
- `--min-score` أدنى درجة ثقة تُعتبر مقبولة تلقائيًا (افتراضي 0.55)

## ملاحظة حول الدقة
لا توجد أداة آلية تعطي دقة 100% في مطابقة صفحات السوشيال ميديا بالاسم فقط، لأن كثيرًا من الصفحات تُسمّى بشكل مختلف عن الاسم الرسمي للمشروع. لهذا صُممت الأداة لتعطيك **درجة ثقة + بدائل** بدل تخمين رابط واحد أعمى، لتراجع أنت الحالات الحدودية بسرعة بدل تصديق نتيجة خاطئة.
